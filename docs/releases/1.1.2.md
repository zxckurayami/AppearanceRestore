# Appearance Restore 1.1.2

Помощник для восстановления оформления VS Code после обновлений.

## Что нового

- Исправлен переход с локальной версии `zxckurayami-local` на издателя
  `zxckurayami` в Marketplace.
- Отсутствующий управляемый стикер заново создаётся из исходной картинки
  в текущем хранилище, без необходимости восстанавливать старую папку.
- Исправляются старые управляемые ссылки Smooth UI, сохраняются посторонние
  CSS/JS-импорты и исходные изображения.
- Если компонент не выбран, сообщение об отсутствующем управляемом файле
  объясняет, как восстановить его. Сообщения доступны на русском и английском.
- Добавлены оформление GitHub, документация, ссылки поддержки и проверки CI.

## Установка

Скачайте `appearance-restore-1.1.2.vsix` из файлов релиза и в VS Code выполните
**Extensions: Install from VSIX**. Контрольная сумма находится в соседнем
`appearance-restore-1.1.2.sha256.txt`.

После обновления выполните **Developer: Reload Window**. При исправлении старой
ссылки на стикер запустите **Appearance Restore: Восстановить оформление**,
выберите Doki Theme и Smooth UI и подтвердите запуск. Custom CSS and JS Loader
подключается необходимым шагом автоматически. Дождитесь окончания и полностью
перезапустите редактор. Не держите локальную и Marketplace-копию включёнными
одновременно.

## Важно

- Требуется VS Code 1.96+ и отдельно установленные плагины оформления.
- В релиз не включены сторонние темы, картинки, настройки или резервные копии.
- Помощник запрашивает подтверждение перед изменениями и не перезапускает VS Code сам.
- Полная визуальная совместимость с каждой версией сторонних расширений
  не гарантируется. Ручная проверка выполнена на Windows.
- Публикация в GitHub Releases не обновляет Marketplace автоматически.

Исходники и инструкция: https://github.com/zxckurayami/AppearanceRestore

## English

Fixes stale managed imports after moving from the former local publisher to
`zxckurayami`. Selected sticker and Smooth UI components are regenerated or
reconnected before missing old files are checked. Original images and unrelated
imports are preserved. Install the VSIX, reload the window, and run Restore
Appearance with Doki Theme and Smooth UI selected. Third-party appearance
extensions must already be installed. GitHub and Marketplace releases are separate.
